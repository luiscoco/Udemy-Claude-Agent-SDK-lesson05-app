01

Narrow the union

Check message.type, then subtype or block.type before accessing shape-specific fields.

02

Read session metadata

system/init describes session_id, model, tools, permission mode and credential source; never expose a key.

03

Inspect assistant blocks

Read message.message.content. Separate text, tool_use and omitted non-text content; response IDs can be shared.

04

Pair tool feedback

Match assistant tool_use.id with user tool_result.tool_use_id. Measure observed request-to-feedback time.

05

Stream incremental text

Enable includePartialMessages. Narrow event.type and delta.type, then append only text_delta.text.

06

Handle final outcomes

Check subtype and is_error; inspect result or errors[], timing, usage, modelUsage and stop_reason. Consume trailing events and catch exceptions.

Your three exercises

  1. Run a one-line message logger, then select each core type in the browser.
  2. Match the Read request and its tool result by ID; inspect observed elapsed time.
  3. Force maxTurns: 1. Preserve the error result and handle a possible subsequent exception.
Live runs show only events actually observed. Compaction, refusals, API failures and thinking blocks are covered by labelled examples. This lesson uses TypeScript; the walkthrough includes a Python field-mapping reference.
