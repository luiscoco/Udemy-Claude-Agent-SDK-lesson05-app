Configure and run the explorer.

Follow the normal run, streaming comparison and one-turn error exercise step by step.

Application labWhat you will learnHow to runArchitecture & workflowCode walkthrough
01

Install the TypeScript application

Use Node.js 24+ and npm. From presentations, enter the application directory. Keep optional dependencies enabled so the SDK runtime is installed.

cd .\agent-sdk\lesson05-message-types
npm ci
02

Create .env and start the server

Copy the safe template only if .env does not already exist. Enter your own key locally, save, and start in this terminal. The start script explicitly loads the optional .env file.

if (!(Test-Path .env)) { Copy-Item .env.example .env }
notepad .env
npm start

Safe configuration template:

ANTHROPIC_API_KEY=your_api_key
CLAUDE_MODEL=claude-sonnet-4-6
PORT=3105

Open http://127.0.0.1:3105. Keep the terminal running. Ctrl+C stops it; restart after configuration changes.

03

Read and inspect a normal run

Choose Read and explain with partial messages enabled. Click Run message explorer once. Wait for success, then inspect init, assistant/tool_use, user/tool_result, stream_event and result. Match IDs in the tool pair cards.

04

Compare streaming and complete blocks

Read the incremental and complete text panels separately. Repeat the same task with Request partial messages off. stream_event should stay at zero while complete assistant blocks and the result still arrive.

05

Force an error and explore examples

Select Force maxTurns: 1. The first response requests Read, leaving too little room for the final explanation. Inspect the actual error subtype, errors array and cost. The runtime can throw after yielding this result; the observer preserves it. Use the examples section for compaction, API errors, thinking and refusal shapes; these are explicitly illustrative.

06

Run the terminal logger

The sample command uses the launching process environment. sample:env explicitly loads .env. Choose read or limit and on or off for partial streaming.

$env:ANTHROPIC_API_KEY = "your_api_key"
npm run sample -- read on
npm run sample -- limit on
# Or load the optional file explicitly:
npm run sample:env -- read off
npm test

Windows troubleshooting

If Git Bash is not found, add CLAUDE_CODE_GIT_BASH_PATH=C:/Program Files/Git/bin/bash.exe to .env after confirming that path exists. A second start detects this application and prints its URL. For another service using the port, stop that service or change PORT in .env. The SDK reads its process environment; a shell variable takes precedence over .env.
