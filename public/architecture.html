This UML sequence explains the one-Read architecture. Partial events interleave with generation; the live log determines the actual order. A result is the completion signal, and trailing observability events may follow it.
Download UML SVG
01

1. Submit task and streaming option

Student → TypeScript host. The host validates the task and the boolean partial-message setting.

02

2. query({ prompt, options })

TypeScript host → Agent SDK. One real query owns the model/tool orchestration.

03

3. Yield system / init

Agent SDK → TypeScript host. Only subtype init provides the model, available tools and session metadata.

04

4. Send prompt and Read definition

Agent SDK → Claude API. The SDK configures Read and sends the task to Claude.

05

5. Generate text or tool_use

Claude API → Agent SDK. A response can contain tool requests or text; actual order varies.

06

6. Yield assistant content blocks

Agent SDK → TypeScript host. The inspector reads message.message.content and retains actual response/tool identifiers.

07

7. Execute permitted Read

Agent SDK → Read tool. The host hook allows only the classroom message-guide.md file.

08

8. Return classroom file contents

Read tool → Agent SDK. The runtime receives the file contents. No stored model answer is injected.

09

9. Yield user / tool_result

Agent SDK → TypeScript host. tool_result.tool_use_id matches the earlier tool_use.id.

10

10. Yield optional stream_event deltas

Agent SDK → TypeScript host. With partial streaming enabled, nested text_delta values populate the incremental panel.

11

11. Yield complete assistant text

Agent SDK → TypeScript host. Complete blocks also arrive, so their text is displayed separately.

12

12. Yield typed result; drain trailing events

Agent SDK → TypeScript host. The observer branches on subtype and is_error, then keeps consuming; later exceptions preserve an observed result.

13

13. Show log, JSON, pairs and outcome

TypeScript host → Student. Students filter by type, select projected JSON, match tool feedback and inspect real accounting.
